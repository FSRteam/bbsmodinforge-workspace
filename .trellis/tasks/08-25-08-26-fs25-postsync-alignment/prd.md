# FS 2.5 post-sync 对齐修复（5项）

## Goal

补回 FS 2.5 同步后遗漏的渲染、原版粒子预览、设置分类本地化和两处编辑器交互，使 `new/` 中的 FSR 行为与最新迁移快照一致，同时保留 FSR 专有的半透明队列、多视口、主题、音频和插件能力。

## Confirmed Facts

- 实际修改目标是 `new/`；`new-fs25-sync/` 是最新 FSR 迁移快照；`temp/bbs-fs-2.3/` 是 FS 上游参考仓库。
- 已于 2026-08-25 重新获取 FS 上游 `master`、`1.21.1` 和 `1.20.1`。当前参考标记仍为 `master=8d99d77f`、`1.21.1=e6b8e382`、`1.20.1=4cdee4ac`。
- FSR 必须保留 `FormTranslucentQueue`，不能采用上游曾经撤回该队列的旧方案。
- 当前队列只在整次 flush 开始时启用混合；单条 `RenderType` 命令结束时会关闭混合，导致后续半透明模型、标签或粒子按不透明方式绘制，表现为材质丢失或发黑。
- `new-fs25-sync/` 已包含两项相关修复：每条延迟命令前恢复标准 alpha 混合；捕获并恢复 Iris 的顶点布局，避免延迟绘制读取错误步长。
- 当前 `VanillaParticleFormRenderer` 在模型编辑器预览中仍依赖世界粒子系统；迁移快照使用独立、有限容量的本地粒子场景，因此不会把预览粒子送进世界队列。
- 设置重组的目标分类为 `camera`、`viewport`、`timeline`、`workspace`、`misc`，界面显示分别为“相机、预览、时间轴、工作区、其他”。旧配置需要无损迁移到新分类。
- 第 4 项的参考行为是：新增身体附件仍追加到所属 Form 的末尾，刷新列表后自动选中并滚动到该新增项。
- 第 5 项的参考行为是：相机模式按钮的右键菜单只显示轨道相机的传送、绑定和正交三项功能；六种相机模式由左键模式选择入口负责。

## Requirements

1. 修复 Color Pose 调低 alpha 后的半透明绘制状态。
   - 每条延迟绘制命令及组合命令中的每个子命令都从已知的标准 alpha 混合状态开始。
   - 延迟的原版 `RenderType` 绘制必须使用捕获时的 Iris 顶点布局，并在结束后恢复原状态。
   - 保留 FSR 现有的透明/不透明双通道、深度写入、排序、Iris 影子跳过及多视口行为。
2. 修复 `bbs:vanilla_particles` 在“其他”分类中的材质预览。
   - 模型编辑器预览使用独立本地粒子场景，支持原版方块、物品和贴图粒子材质。
   - 预览场景有粒子数量上限、独立时钟和完整渲染状态恢复；不得污染世界粒子或世界半透明队列。
   - 世界中的原版粒子伪装仍沿用现有生成路径。
3. 恢复设置分类与本地化。
   - 设置注册按相机、预览、时间轴、工作区、其他五类拆分，旧配置值无损迁移。
   - 所有受支持语言文件中的旧设置键按新分类迁移，不能出现空值或裸键。
   - `en_us` 和 `zh_cn` 的五个分类标题、说明及相关新控件文案完整；其他语言至少保留已有本地翻译，新增分类标题不得为空，无法可靠翻译的说明可回退英文。
   - 保留 FSR 额外设置，不得用上游整文件覆盖。
4. 新增身体附件后，列表自动定位到末尾的新附件并进入编辑状态。
5. 相机模式按钮的右键菜单只显示三项轨道相机功能，不重复显示六种相机模式。

## Acceptance Criteria

- [ ] Color Pose alpha 从 1 调到小于 1 时，模型、标签、方块/物品层和粒子材质不再变黑或丢失，多个半透明命令连续绘制时仍保持透明。
- [ ] Iris 开启和关闭两种路径均不会因延迟顶点布局错误出现三角扇、破面或材质错乱。
- [ ] `bbs:vanilla_particles` 在模型编辑器的“其他”分类中可持续显示真实原版粒子材质；关闭/切换预览后不会在世界遗留粒子。
- [ ] 设置界面出现相机、预览、时间轴、工作区、其他五个分类；中英文标题、说明和设置项无空值/裸键，其他语言不丢失已有翻译。
- [ ] 旧 `editor`、`debug`、`personalization`、`appearance`、`dc`、`shader_curves`、`multiskin`、`entity_selectors` 配置在首次加载后迁移到新分类，用户值不被默认值覆盖。
- [ ] 连续新增多个身体附件时，每次都自动选中并滚动到刚追加的末尾项。
- [ ] 相机模式按钮右键菜单在任意模式下只包含传送、绑定、正交三项轨道相机功能；六种模式不出现在该右键菜单中。
- [ ] 相关源级回归测试、`compileJava`、`compileClientJava`、定向测试、`check` 和 `build` 通过；人工游戏内渲染验证若无法自动完成，必须明确记录为待验收。

## Out Of Scope

- 不替换 FSR 的粒子主系统，也不迁移 FS 已被 FSR 明确拒绝的半透明回滚提交。
- 不重构无关设置、影片录制、多视口、音频、主题或插件功能。
- 不改变模组版本号和产物名称。
