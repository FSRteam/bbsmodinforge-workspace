# webremote 手机端体验：右侧操作中枢 + WASD/飞行 + 虚拟鼠标 + 鼠标流畅度

父任务：`.trellis/tasks/08-12-wr-frontend-overhaul/`（共同约束见父 prd「边界与约束」，全部适用）。

## Goal

在不改变 wire 协议与服务端行为的前提下，系统性优化 `bbs-web-remote` 手机端操作体验：主操作收纳为屏幕右侧竖排按钮中枢 + 二级目录/面板，补齐 WASD 移动（虚拟摇杆）、飞行切换、虚拟鼠标（触控板）模式与鼠标点击操作，并把输入状态发送从 30Hz 提升到 60Hz 合帧以消除鼠标卡顿。

## 背景（技术事实）

- 浏览器端为无构建 IIFE 命名空间模块（纯 `<script>`，禁新框架/构建工具/npm 依赖）。
- 输入状态发送原本 30Hz 上限 + 33ms 轮询，是手机端鼠标卡顿的直接来源。
- 服务端 `CoControlCoordinator` 对 INPUT_STATE 已有早期限流 `EarlyRate(120 突发, 60/s 持续)`，因此客户端提到 60Hz 不会触达服务端限流，安全。
- 移动端旧 UI 是底部横条（L/R/M + 修饰键 + 键盘）；≤560px 时工具栏的控制/键盘入口被 `display:none` 隐藏导致不可达（ui-overhaul A2 已解决可达性，本任务在其上重构操作中枢）。

## 需求

### R1 右侧操作中枢与二级目录

- 手机端主要操作收起来在屏幕右侧：竖排按钮中枢（主按钮组），点击主按钮展开二级目录/面板。
- 中枢收纳：移动/飞行、鼠标模式切换、更多菜单等入口；二级面板展开时不遮挡画布核心区域、不与其他 HUD 浮层互相遮挡（沿用 ui-overhaul 插槽层约束）。
- 与 ui-overhaul 产出的令牌/插槽/浅色主题体系一致；不复活手工避让坐标。

### R2 WASD 摇杆与飞行

- WASD 移动操作：虚拟摇杆，支持斜向（双方向同时按下）。
- 飞行模式可用：飞行切换按钮等效双击空格；飞行中 Space 上升 / Shift 下降（长按持续、松开停止）。
- 摇杆与飞行按键均在协控权限（持有操作权）下才生效；权限丢失时全部按键立即释放。

### R3 虚拟鼠标模式与点击操作

- 两种触控模式可切换：
  - 直接点按（绝对定位）：现状行为，点哪打哪。
  - 虚拟鼠标（触控板）模式：相对移动 + 画布上可见光标；轻点=点击，长按拖拽=按住拖动，双击=双击。
- 模式切换入口放在右侧中枢；切换即时生效并持久化（localStorage）。
- 虚拟鼠标模式不改变 wire 协议——仍在客户端把相对位移换算为绝对坐标后按既有消息发送。

### R4 鼠标流畅度

- 输入状态发送从 30Hz 上限 + 33ms 轮询提升为 60Hz + `requestAnimationFrame` 合帧（每帧最多发一次，有变化才发）。
- 服务端限流为 `EarlyRate(120 突发, 60/s 持续)`，客户端 60Hz 持续在限流窗口内，安全；不改服务端。

### R5 持久化与可达性

- 触控模式（直接点按 ↔ 虚拟鼠标）选择持久化到 localStorage，刷新后保持。
- 右侧中枢在各断点（>900 / 560–900 / <560 / <400）可达、不遮挡、不破坏既有 aria/focus-visible/reduced-motion 基础。
- 自由发挥项（允许但不强制）：游戏操作键（跳/蹲/跑）、更多菜单（打开 BBS、交出操作权、参与者、诊断、主题切换入口）。
