# 游戏内复测矩阵

## 1 / 2：伪装重入与半透明 MobForm

1. 0 打开 Dashboard，切到伪装菜单，编辑一个普通 Form。
2. ESC 退出，不切换菜单；分别用 B 和 0 重入并再次编辑。
3. 用鼠标移动预览相机，确认世界背景持续跟随；悦灵、恼鬼、玩家、猪灵、旋风人的身体和半透明层均完整显示。
4. 重复 10 次退出/重入，确认没有只在一定距离或角度消失的层。

## 3：模型方块重入交互

1. 右键一个模型方块，保持模型方块菜单为当前菜单后 ESC。
2. 分别用右键同一方块和 0 重入。
3. 确认 WASD 移动、滚轮调速正常，视角从玩家当前相机重新建立并聚焦当前工作区域。
4. 进入模型方块的伪装编辑器，确认其 immersive 相机正常。

## 4 / 6：影片伪装选择与视觉效果

1. 影片菜单中打开 replay/伪装选择并编辑悦灵、恼鬼、玩家、猪灵、旋风人。
2. 确认 3D 预览立即显示完整模型，不需要等待下一世界帧。
3. 分别在无光影、Iris 光影、Iris 阴影 pass 下比较 BBSFS：透明层、深度遮挡、实体阴影和 `shaderShadow` 开关行为一致。

## 5：被破坏模型方块的子菜单

1. 在模型方块菜单进入伪装子菜单，切到伪装菜单并 ESC。
2. 破坏对应模型方块，再进入模型方块菜单。
3. 确认旧伪装子菜单已消失、无旧选中项，点击/编辑不会崩溃。

## 7：S / R 快捷键

1. 模型 Form 编辑器选中一根肢体。
2. 连续按 S，确认依次进入 X、Y、Z 缩放；点击 gizmo 中心仍执行统一缩放。
3. 连续按 R，确认可依次到达 view、sphere（按设置为 arcball/trackball）、X、Y、Z。
4. 每个模式输入数值并确认/取消一次，检查切轴只撤销当前未确认预览，不污染已提交值。

## 8：动作模型性能

1. 选取一个顶点多、骨骼多的 BOBJ 模型，先关闭动作记录编辑器帧率。
2. 开启 idle/running 动作，在鼠标位于模型预览内（拾取 stencil 激活）时记录帧率。
3. 确认动画和骨骼点击正确，且不再因 normal + stencil 同帧双重 CPU 蒙皮产生明显帧率骤降。
4. 开关 Iris 再测一次，确认切线只在新姿态上传时重算。
