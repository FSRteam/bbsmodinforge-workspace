# 圆形声音伪装 Morph

父任务:`07-26-fsr-sound-morph-parent` · 依赖:`07-26-fsr-sound-acoustic-core`(必须先完成)

## Goal

交付第一个可用的声音伪装目标:**圆形(球形)声音 Form** —— 以伪装目标位置为球心向各方向均匀发声,半径可编辑,能用关键帧控制何时开始/停止播放。

本任务是「把声学核心接到 BBS Form 体系上」的**首次贯通**:走完注册 → 序列化 → 编辑面板 → 实际发声的完整链路。世界内可视化不在本任务(归子任务 3,与锥体共用绘制原语)。

## Requirements

### R1 Form 类型

- R1.1 `SoundSphereForm extends AbstractSoundForm`(基类来自子任务 1),追加 `ValueFloat radius`。
- R1.2 实现基类的形状增益抽象方法:球形各向同性,方向增益恒为 `1`。
- R1.3 覆写 `getDefaultDisplayName()`,给出可读名称。
- R1.4 以 `Link.bbs("sound_sphere")` 注册进 `FormArchitect`(`BBSMod.java:553-566` 的注册块)。

### R2 客户端接入

- R2.1 注册 `FormRenderer` 到 `FormUtilsClient.java:78-89` 的静态块;UI 预览给出可辨识的图标/占位表现。
- R2.2 注册 UI 编辑器到 `UIFormEditor.java:133-144` 的静态块。

### R3 编辑面板

- R3.1 `UISoundSphereFormPanel extends UIFormPanel<SoundSphereForm>`,分组呈现:音源 / 发射形状 / 衰减 / 反射。
- R3.2 音频选择复用 `UISoundOverlayPanel`(`ui/framework/elements/overlay/UISoundOverlayPanel.java`,构造签名 `(Consumer<Link>, UIContext)`),用法照 `UIAudioClip` 既有模式。
- R3.3 数值参数用 `UITrackpad` 并限幅;布尔用 `UIToggle`;衰减模型用循环选择控件。
- R3.4 提供试听按钮,在编辑器中即时预览当前参数(PRD R7.3)。
- R3.5 `startEdit(form)` 中把 Form 数据同步回 UI 控件(照 `UIMobFormPanel` 既有模式)。

### R4 播放贯通

- R4.1 该 Form 在世界中存在且 `playing` 为真时,按声学核心算出的增益与位置实际发声。
- R4.2 关键帧控制 `playing` 时,正播 / 倒播 / scrub / 循环四种情形播放行为正确(无重复播放、无漏播、无残留音源)。
- R4.3 关闭反射时,表现与一个普通 3D 定位音源等价。

## 2026-07-27 用户回归补充

本轮同时修正球形与圆锥声音 Form 的共享关键帧和声学运行时，新增要求如下：

- 回放编辑器不再为声音字段逐项暴露轨道，而是提供五条真实复合轨道：
  - `声音`：音频、播放、音量、音调、循环、起始偏移；
  - `发射形状`：球形半径，或圆锥范围/内外锥角/外部增益；
  - `可视化`：辅助图形开关与颜色；
  - `距离衰减`：模型、参考距离、滚降、空气吸收；
  - `反射`：总开关、次数、衰减、方块/实体反射、方块/实体穿透。
- `声音` 关键帧中的音频按钮必须打开 `UISoundOverlayPanel`，不得打开纹理选择器。
- 每次点击试听都必须停止并替换该预览音源，从片段起点重新播放。
- 方块和实体分别具有反射开关与穿透开关。`穿过=true` 时，该类别既不遮挡直达声，也不作为反射面；`穿过=false` 且对应反射开启时，该类别参与首次命中和反射。
- 方块探测必须使用真实世界碰撞面；实体反射使用实体 AABB 的最近可见面，并排除声音 Form 所附着的实体。
- 已有影片中的旧独立声音轨道继续读取和应用；新建轨道使用复合格式，复合轨道与旧轨道同时存在时复合轨道优先。

追加验收：

- [ ] 五条复合轨道均显示中文名称，一次 K 帧可完整编辑对应参数组。
- [ ] 声音关键帧打开音频资源面板，连续点击试听可每次从头播放。
- [ ] 方块反射开启且方块不穿透时，可听到由周围实际方块面生成的反射；穿透方块后该遮挡和反射同时消失。
- [ ] 实体反射开启且实体不穿透时，实体可遮挡并生成反射；穿透实体后该遮挡和反射同时消失。

## 2026-07-27 第二轮用户回归补充

- 影片音频 `AudioClip.volume` 与球形/圆锥声音 Form 的 `volume` 均不得设置有限上限；所有现有音量面板和声音关键帧编辑器必须继承该无上限范围，同时继续拒绝负音量。
- `show_guide=true` 在普通世界中必须持续显示辅助图形，不得依赖全局“显示全部”开关。Film 回放编辑器只显示当前 Replay（或显式“显示全部”）的辅助图形，且鼠标移出监视器后不能因 picking 停止而消失。
- 所有世界空间声源，包括直达声和每个反射声源，都必须使用 OpenAL 可定位的单声道缓冲。普通 Film/UI 播放仍保留资源原始立体声；立体声空间变体从同一次解码下混，不得改变音频时长、seek、looping 或资源所有权。

追加验收：

- [ ] 影片音频、声音 Form 面板及声音关键帧均能输入并保存大于 `2` 的音量值；负值仍夹取到 `0`。
- [ ] 普通世界开启可视化后持续可见；Film 当前 Replay 的辅助图形在鼠标移出监视器后仍持续可见，切换 Replay 后归属同步切换。
- [ ] 立体声资源普通播放保持立体声；同一资源的直达声和反射声分别从各自世界坐标产生方向与距离变化。
