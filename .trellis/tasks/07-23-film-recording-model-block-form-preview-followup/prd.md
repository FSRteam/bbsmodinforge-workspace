# 修复影片外部录制、模型方块重入与 Form 预览回归

## Goal

对照 BBSFS 的可用行为，修复影片外部录制崩溃、模型方块菜单同项重入后的输入失效、伪装预览发光/阴影视觉偏差，以及带动画 Form 的编辑预览明显掉帧。

## Confirmed Facts

- “录制回放 -> 外部录制”在关闭仪表盘后仍通过原面板读取当前 Film、Replay 和游标；FSR 的关闭生命周期会同步清理面板资源，因此关闭后读取不再安全。
- 仪表盘已恢复当前面板的 `disappear()`/`appear()` 配对，但同一面板重开不会触发面板切换事件；模型方块的 WASD 和滚轮由仪表盘根级轨道相机控件持有，相关控制状态没有在同项重开时完整重建。
- FSR 为半透明世界渲染增加了延迟队列；UI/Form 编辑预览必须保持即时绘制，并与 BBSFS 的发光面、混合、深度和阴影表现一致。
- 现有 BOBJ 优化仅复用相同骨骼矩阵结果，真实动画预览仍存在明显掉帧；优化不得跳帧、降采样或改变 IK、物理和动画语义。
- 本任务只修改 `new/` 代码仓库；根仓库的主题任务改动、`new/.github/REPOSITORY_SETTINGS.md` 和 `new/docs/theme-spec/` 不属于本任务。

## Requirements

- 外部录制必须先按身份取得当前 Film、Replay 索引、游标和所需 Form 数据，再关闭仪表盘并启动录制，不能在关闭后解引用 UI 面板状态。
- 外部录制启动失败、Film/Replay 已失效或世界发生切换时必须安全终止，不能留下录制器、玩家 Form、鼠标或相机所有权。
- 通过右键模型方块或 `0` 键重开仍被暂存为当前项的模型方块菜单时，必须恢复根级轨道相机控制、WASD、滚轮速度和面板快捷键。
- 右键模型方块进入面板时，相机必须聚焦到该模型方块；仅按 `0` 重开时保留正常仪表盘相机语义。
- 伪装选择和 Form 编辑的 3D 预览必须即时渲染半透明层，并与 BBSFS 对同一模型的发光面、阴影、深度和混合结果一致。
- 悦灵、恼鬼、玩家、猪灵、旋风人等曾受影响的 MobForm 在伪装和影片选择预览中必须完整可见。
- 动画 Form 预览应消除同一帧内可复用的重复动画求值、CPU 蒙皮或 GPU 上传，同时保持每帧动画、IK、物理和拾取结果正确。
- 保持既有公开 API 描述符和 NeoForge 1.21.1 迁移约束，不回退到 Fabric 或旧映射接口。

## Acceptance Criteria

- [ ] 在影片菜单选择任一 Replay，执行“录制回放 -> 外部录制”不会崩溃，并能开始、停止和应用录制结果。
- [ ] 外部录制在 Replay 被删除、Film 被切换、断线或退出世界时安全清理，且不会错误应用到相等但非同一身份的 Replay。
- [ ] 选中模型方块菜单后退出，再右键模型方块重入，WASD 和鼠标滚轮立即可用，相机自动聚焦到目标方块。
- [ ] 选中模型方块菜单后退出，再按 `0` 重开，WASD 和鼠标滚轮立即可用，无需先切换其他菜单。
- [ ] 反复执行上述重入流程不会重复注册相机控制器或遗留输入焦点/快捷键所有权。
- [ ] 伪装菜单及影片菜单的 Form 编辑预览中，目标 MobForm 均可见，发光面和阴影结果与 BBSFS 基线一致。
- [ ] UI/Form 预览不会加入世界半透明队列；世界中的半透明 Form 仍按正确阶段排序和绘制。
- [ ] 带动画的 Form 编辑预览不再出现由同帧重复求值/上传造成的明显掉帧，且动画时间、IK、物理、发光、阴影和拾取不降级。
- [ ] 新增针对录制顺序、同菜单重入输入恢复、预览渲染边界和动画缓存失效条件的回归测试。
- [ ] 相关测试、客户端编译和构建通过；生成的测试 JAR 可由 PR 工作流下载。

## Out of Scope

- 不重做影片录制 UI 或模型方块编辑器布局。
- 不通过降低预览分辨率、限制帧率、跳过动画帧或关闭 IK/物理来掩盖性能问题。
- 不改变世界半透明渲染队列的既定排序目标，除非修复预览隔离所必需。
- 不包含主题系统、仓库治理或工作流文档的无关改动。

## Open Questions

无阻塞产品问题；视觉验收以 `old2.0/bbs-fs` 对应行为和受影响实体的并排测试为基线。
