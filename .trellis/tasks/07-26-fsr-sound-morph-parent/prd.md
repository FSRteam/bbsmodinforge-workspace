# FSR 声音伪装目标(圆形/圆锥)

## Goal

给 BBS FSR 新增两个**声音伪装目标(sound morph)**,让创作者可以把"一个会发声的点"当作伪装目标放进场景,并用关键帧控制它在时间轴上何时开始/停止播放某段音频。声音不是简单的 2D 播放,而是带**可编辑声学模型**:发射形状、发射半径、距离衰减、反射次数与反射衰减等。编辑器里要能**在世界中直观看见**声音的传播范围与强度分布。

两个目标形状:

- **圆形声音伪装(Sphere)** — 以伪装目标位置为球心向各方向均匀发射,半径可编辑。
- **圆锥声音伪装(Cone)** — **圆锥顶点即播放点**,沿锥轴向外张开,**锥高 = 最远传播距离**,张角与朝向可编辑。

编辑交互参考插件 [`quaIett/bbs-irlights-addon`](https://github.com/quaIett/bbs-irlights-addon)(给 BBS 加灯光 morph 的 addon,同样是"形状参数 + 世界内可视化 + 编辑面板"的组合)。研究报告见 `research/irlights-addon-reference.md`。

## 声学实现档位(已与用户确认)

**参数化模拟**:音频经由项目现有音频播放通道发声,反射/衰减等声学参数在客户端换算为**多个带独立延迟 + 独立增益的虚拟声源**(image-source 法)。不引入 OpenAL EFX 混响扩展,不接管原生音源生命周期。

## Requirements

### R1 两个 Morph 类型

- R1.1 新增 `sound_sphere` 与 `sound_cone` 两个 morph 类型,按项目既有 morph 注册机制接入,可在伪装选择器中被创建、复制、序列化与还原。
- R1.2 两者共享同一套声学参数基类,仅"发射形状"部分不同(球:半径;锥:顶点/朝向/锥高/内外张角)。
- R1.3 圆锥语义硬约束:**顶点 = 播放点**(morph 自身位置),锥高即最远传播距离,声音强度沿轴向从顶点向底面递减。

### R2 关键帧驱动播放

- R2.1 提供**触发型**关键帧轨道:在指定帧"开始播放 / 停止播放",而非连续插值。倒放、跳转(scrub)、暂停、循环播放都要行为正确,不产生重复播放或漏播。
- R2.2 连续参数(音量、音高、发射半径 / 锥高、内外张角、朝向)支持常规插值关键帧。
- R2.3 音频起播支持**起始偏移**,时间轴 seek 到片段中部时声音从对应位置续播,而不是从头播。

### R3 声源与发射参数

- R3.1 音频选择:从项目现有音频资源库中选择一段音频;支持音量、音高、循环、起始偏移。
- R3.2 发射形状参数:
  - 球:半径。
  - 锥:锥高(最远距离)、内锥角、外锥角、朝向(yaw/pitch)、外锥增益。
- R3.3 方向性:锥形在内锥内为全增益,内外锥之间平滑过渡到外锥增益,外锥之外按外锥增益(OpenAL 标准锥体模型语义)。

### R4 距离衰减

- R4.1 提供可选衰减模型:**线性 / 反比(inverse) / 指数(exponential)**,配 `参考距离(reference distance)`、`最大距离(max distance)`、`衰减系数(rolloff factor)`。
- R4.2 超过最大距离后完全静音(可选 clamp 行为)。
- R4.3 可选**空气吸收**项:随距离额外衰减,近似高频吸收(参数化模拟档位下以额外增益衰减实现,不做真实滤波)。

### R5 反射

- R5.1 反射开关、**反射次数**(0..N)、**每次反射的衰减系数**(材质吸收)。
- R5.2 反射声源按 image-source 法生成:每个反射声源有独立的**传播延迟**(由额外路程 / 声速换算)与独立**增益**(距离衰减 × 反射次数次吸收衰减)。
- R5.3 反射搜索受发射形状约束(球:各向;锥:锥体覆盖方向),且受最大距离与反射次数双重截断。
- R5.4 反射声源总数有硬上限,超限时按增益排序保留最强的若干个,避免音源耗尽。

### R6 可视化

- R6.1 编辑器中选中该 morph 时,在世界内绘制发射形状:球为线框球,锥为线框圆锥(顶点在播放点)。
- R6.2 **强度可视化**:用颜色/透明度梯度表示不同距离处的相对强度(等响度分层),让用户直观看到"衰减到哪儿基本听不见"。
- R6.3 参考距离、最大距离以独立标记(不同颜色的环/截面)区分显示。
- R6.4 反射开启时可选显示反射路径示意。
- R6.5 可视化仅在编辑模式/选中态显示,不影响最终渲染输出。

### R7 编辑器面板

- R7.1 每个 morph 类型有对应编辑面板,按项目既有 morph 面板约定组织,复用既有 UI 控件基类。
- R7.2 面板分组:音源 / 发射形状 / 衰减 / 反射 / 可视化,参数可 K 帧的要能直接进关键帧轨道。
- R7.3 提供试听按钮,在编辑器中即时预览当前参数下的效果。

## 全局约束

- C1 **不破坏既有功能**:不修改既有 morph 类型行为,不改动原生 SoundEngine 生命周期;新 morph 缺省关闭反射时,行为退化为一个普通的 3D 定位音源。
- C2 序列化向后兼容:新增字段全部可选并有默认值;旧存档读取不报错。
- C3 热路径零分配:每帧求值(衰减、可视化顶点)不做临时对象分配;声源列表复用。
- C4 音源预算:反射虚拟声源数量受上限约束,不得挤占其他音效通道。
- C5 裸 JVM 测试红线延续:新代码不得在测试进程触发 `BBSMod.<clinit>`。
- C6 构建验证以**真实 exit code + 日志双确认**,禁止管道结尾判断成败。
- C7 视频导出/录制路径下声音行为需与实时播放一致。**已确认当前导出听不到声音 Form**(架构缺口,详见 `design.md` §9),由子任务 4 解决;导出须正确处理**单声道与立体声**两种声道设置(立体声按监听者朝向做等功率声像,单声道纯增益求和)。
