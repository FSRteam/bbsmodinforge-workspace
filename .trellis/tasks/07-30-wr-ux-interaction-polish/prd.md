# P2 交互打磨

## Goal

降低日常使用的心智负担与\"点了没反应\"类困惑。收敛控制权（permission/role/lease）的概念与文案；诊断面板默认精简、完整字段收进高级折叠；触摸端右/中键与修饰锁做到可发现且防粘滞；给离线 demo 明确进入/退出与 file:// 提示；空状态按当前权限给出正确引导。纯前端（`app.js` + `styles.css` + `index.html`）。

- 诊断面板 40+ 字段 500ms 全量刷新无分级：`app.js:5073`、`index.html:163-213`
- 触摸右/中键、修饰锁只在工具栏、折叠即消失：`app.js:2694/2746-2750/2753-2758`、`572-573`

## Requirements

### 控制权文案收敛
- 把 permission / role / lease 三层向用户收敛为**少数可懂状态**：例如\"观看中\" / \"可控制（等待操作权）\" / \"操作中\"，配一句解释。
- 控制按钮文案与 `roleStatus`/`leaseStatusPill`/`leaseSummary` 表述统一、不自相矛盾；保留底层协议语义不变（只改展示层）。
- 观看者点\"请求控制\"等操作时，用持久的按钮态/说明而非仅一次性 toast 表达\"为何不可用\"。

### 诊断分级
- 诊断面板默认只显示**少数关键指标**（连接状态、UI/媒体 FPS、分辨率、码率、操作权），完整 40+ 字段收进\"高级\"折叠区，默认收起。
- 记住用户的展开偏好（localStorage）。刷新频率对收起的高级区可降频以省开销。

### 触摸可发现 + 防粘滞
- 触摸端右/中键切换与修饰锁**不因工具栏折叠而消失**：提供折叠时仍可达的入口，或移出可被折叠隐藏的区域。
- 修饰锁（Shift/Ctrl/Alt）粘滞时有**明显视觉常驻提示**，并提供一键全部释放；释放/换屏时确保清除（复用 `releaseAll`）。
- 首次触摸时给一次性简短手势说明（单指=指针/点击，双指=缩放/平移/滚动），可关闭不再提示。
- 缓解\"轻微拖动单击在不同坐标 press/release\"：低于阈值的抬手在**同一坐标**完成 press+release。

### demo 与空状态
- 离线 demo 提供**可见的退出/返回连接**入口；\"fixture\"等术语改为用户可懂措辞（\"离线演示\"）。
- file:// 或 `?demo=1` 自动进入 demo 时，给明确\"当前为离线演示，非真实连接\"的可见标识。
- 空状态文案按**当前权限**给出正确引导：无协控权限的 viewer 不再被引导去点会被拒绝的\"打开 BBS\"；改为提示\"在 Minecraft 中打开面板\"或\"请求协控\"。
- 桌面\"需聚焦画布才能用鼠标键盘\"的关键提示从 `sr-only` 提升为视力用户可见（首次/未聚焦时的画布内提示）。

## Acceptance Criteria

- [ ] 控制权状态在按钮 / roleStatus / lease pill / summary 间表述一致，用户能分清\"观看/可控制/操作中\"；底层 lease 协议行为不回归。
- [ ] 诊断面板默认精简（少数关键项），完整字段在默认收起的\"高级\"区；展开偏好被记住。
- [ ] 触摸端在工具栏折叠时仍能切换右/中键与修饰键；修饰锁有常驻可见提示且可一键释放。
- [ ] 首次触摸有一次性手势说明，可永久关闭。
- [ ] 轻点不再产生跨坐标微拖拽。
- [ ] 离线 demo 有可见退出入口；file:///`?demo=1` 有\"离线演示\"可见标识。
- [ ] 空状态不再引导无权限 viewer 点\"打开 BBS\"；按权限给出正确下一步。
- [ ] 桌面未聚焦画布时有可见（非仅 sr-only）操作提示。
- [ ] 前端 Node 回归通过；无 wire/协议改动。

## 约束

- 纯前端；只改展示/交互层，不改协议、lease 服务端语义、输入编码。
- 新增用户文案需可本地化（与 `wr-ux-error-i18n` 的 lang key 约定一致，补 en/zh）。
- 复用现有 `FloatingToolbar`/`RemoteInput`/`updateControlUi`/`updateDiagnostics`，增量改造。

## Out of Scope

- 响应式重排 BBS 桌面 UI。
- 触控手势模型的大改（只做可发现性与防粘滞，不重写单/多指状态机）。
