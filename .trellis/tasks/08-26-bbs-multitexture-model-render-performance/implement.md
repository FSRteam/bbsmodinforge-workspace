# 执行计划：BBS 多贴图模型方块渲染性能优化

## 1. 现状与基线

- [ ] 记录当前 Cubic/BOBJ 渲染调用边界和已有回归测试。
- [ ] 确认 `new` 层规范与透明/光影状态契约。

## 2. 实现

- [ ] 为 `ModelVAORenderer` 增加批次内无状态 VAO 绘制入口，统一 shader 生命周期。
- [ ] 在 `CubicVAORenderer` 中缓存材质纹理解析并按纹理分批即时绘制；延迟透明命令维持独立边界。
- [ ] 在 BOBJ 路径中复用一次骨骼矩阵数组，并减少每网格快照分配；必要时复用 shader 生命周期。
- [ ] 增加源码/逻辑回归，覆盖同纹理合批、纹理切换、BOBJ 矩阵复用及透明分支。

## 3. 验证

- [ ] 运行最小相关测试。
- [ ] 运行 `./gradlew.bat compileClientJava`。
- [ ] 运行 `./gradlew.bat build`，确认实际执行的任务和退出码。
- [ ] 检查最终 diff，确认没有修改用户已有未提交改动。

## 风险点

- shader uniform 必须在每个 VAO 绘制前更新，不能误把第一个组的矩阵复用于整个批次。
- 延迟透明材质必须保留自己的纹理和深度策略。
- 动画纹理、缺失纹理和拾取 light buffer 的状态不能跨帧污染。
