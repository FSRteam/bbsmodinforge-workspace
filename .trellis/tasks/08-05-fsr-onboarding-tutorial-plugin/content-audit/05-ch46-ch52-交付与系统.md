## 批次概览与最严重问题 Top5

**总体评价**：本批次的"文案与真实 UI 对齐度"是各批次里最好的——影片选项/队列导出六条状态文案、插件面板全部按钮与十种状态、导入器八个转换器名称、主题五色、语言编辑器风险提示、实用工具面板重载组、图形计算器帮助语等，逐条与 zh_cn 文案核对**几乎全部一致**，引用严谨。但批次级结构有一个硬伤：**规划中的"FFmpeg 配置与排错""视频导出：F4 手动与 F6 影片""导出参数"三章从未交付**（已核实 `chapters-39-45-skeleton.json` 实际内容是粒子第七幕，`story-outline.json` 第八幕与 `chapter-plan.json` ch43–45 的对应章节均无落地文件），导致本批从"批量导出"冷启动，把用户从未学过的单部影片导出（F6）当作已知前提。

**Top5 最严重问题**：

1. **[C] 基础视频导出教学整体缺失（跨章前置断裂）**。全篇没有任何一章手把手教"把一部影片导出成视频"。F4 在全部交付章节中从未用于教学；F6 仅在 ch46_s1 台词和 ch46_s6 指令中出现，且都以"你已经会了"的口吻。规划（chapter-plan ch43/44/45：FFmpeg 配置与排错、视频导出 F4/F6、导出参数分辨率/帧率/编码）三 chapter 全部落空。需全局确认补章。
2. **[A] ch46_s6 排错流程让用户"按 F6 导出"，而可点击路径存在且该键未标「默认」**。摄像机编辑器工具栏有"录制视频"按钮（bbs.ui.camera.tooltips.record），同栏还有"打开视频设置…""打开视频文件夹…"；F6 属于 Minecraft 全局注册键（key.bbs.play_film_and_record），可在 MC 控制 设置改绑，教程规则要求写「默认」并给自查途径——而 F9 键位列表只覆盖 Keys.java 编辑器键，查不到全局 F6，必须指向 MC 按键设置。
3. **[D] ch52_s1 "打开 **实用工具面板**"没有交代任何入口**。Dashboard 九个面板按钮中没有它（ui-inventory registered_panels 核实）；唯一已知入口是 Dashboard 内默认 F6（keybinds dashboard.utility_panel → UIKeys.UTILITY_TITLE），而 F6 这个信息只在第一章键位表出现过一次，隔了 51 章未复述，本章却连键都不提。
4. **[D] ch47 导入器的转换入口在哪里全程未交代**。ui-domains 有全部转换器名称和成功文案（"拖放的文件已被 %s 成功处理！"暗示拖放触发流），但 ui-inventory 中不存在导入器面板类；instruction 直接说"选择匹配的转换入口"，用户无从找到入口，userWillSee 也无法对照验证。
5. **[C/D] 导出参数只看不练**。"帧分辨率""帧率"在 ch46_s2 被当作"检查一下就行"的已知项，编码器参数、720p/1080p/4K/竖屏预设、运动模糊、保持帧等在 ch48_s4 只有一句"查看"；用户从未被教过如何为一个目标平台选择导出规格。

## 逐章分析

### ch46 批量导出：一次处理多部影片（6 步）

整体评价：章内流程设计合理（概念→备标签→启动队列→异常→核对→排错），队列菜单路径"影片选项 → 从打开的标签页导出队列"与六条状态文案经 ui-domains film_core 域逐字核实无误。但它建立在一个从未交付的前提上：用户会单片导出。作为"交付阶段"的第一章，冷启动感明显。

- **[C]（全局，落点本章）ch46_s1**："单部影片按 F6 导出就够了" —— 单片导出教学在规划中属 ch44《视频导出：F4 手动与 F6 影片》，交付文件中不存在（chapters-39-45 实为粒子章）。台词把未教的操作当常识，新用户在这里第一次听说 F6 却得不到任何操作指引。建议：要么全局补齐基础导出章，要么在本章 s1/s2 之间插入一步单片导出实操（走按钮路径）再引入队列。
- **[A] ch46_s6**："单独打开那部影片并按 F6 导出" —— 存在可点击替代：摄像机编辑器工具栏"录制视频"按钮（bbs.ui.camera.tooltips.record，同栏还有"打开视频设置…""打开视频文件夹…"两个兄弟按钮佐证工具栏存在）；且 F6 是 MC 全局注册键（key.bbs.play_film_and_record，见 _archived-wrong-keybinds.md.bak 按键表），可在 MC 控制 设置改绑。注意：**按 F9 自查对此键无效**——F9 打开的是 Keys.java 编辑器键位清单，不含全局键，正确自查途径是 Minecraft 设置→按键绑定。建议改为："打开该片进入摄像机编辑器 → 点击工具栏 **录制视频** 按钮（鼠标悬停可见按钮名）导出；熟练后也可用全局默认键 **F6**（播放影片并录制，可在 Minecraft 设置→按键绑定 中查看/修改）"。
- **[A·轻] ch46_s1 dialogueMale/dialogueFemale**："一部影片按 F6 就好啦～" —— 台词层面的同一问题，与上条同源修法；若补了基础导出章则自然解决。
- **[D] ch46_s2**："检查 **视频导出设置** 中的 **帧分辨率** 与 **帧率**" —— "视频导出设置"弹窗（bbs.ui.video_settings.title，标签核实存在）怎么打开没说；证据表明摄像机编辑器工具栏有"打开视频设置…"按钮（bbs.ui.camera.tooltips.open_video_settings），另有 bbs.ui.video_settings.edit"编辑设置…"。建议补一句入口。
- **[D] ch46_s5**："打开 **导出路径** → …检查 **文件名格式** 生成的名称是否可分辨" —— "导出路径"在视频导出设置弹窗内（bbs.ui.video_settings.path），"文件名格式"则是设置分类项（bbs.config.video.filename_format，仅存在于 设置→视频录制，不在 video_settings 弹窗标签中）；两者不在同一界面，混在一句话里会让用户在弹窗里找不到后者。建议分开指路。
- **[D] ch46_s6**："启用 **编码器日志**" —— 未说明位置。实际在 设置→视频录制→编码器日志（bbs.config.video.log）。排错步骤最忌让用户先找开关。
- 其余核实通过：s2 标签操作四项（新标签页/关闭左侧/右侧/其他标签页，bbs.ui.film.tabs.*）、s3 全部状态文案（bbs.ui.film.render_queue.*）、s5 占位符列表与 {name} 等（bbs.config.video.filename_format-comment）、helpers 三项（导出后打开文件夹/导出后播放提示音/编码器日志均为真实配置标签）。

### ch52 音频与语言编辑器：完善你的工作流（5 步）

整体评价：作为收尾章，实用工具面板的重载组（模型/纹理/声音/地形/语言）、编译/分析、语言编辑器全部工作流按钮（缺失筛选/参考语言/标记完成/JSON 复制粘贴及其备份警告）逐字核实一致，风险提示（粘贴 JSON 先备份）忠实转述宿主警告，收束步的全课程回顾得体。核心缺陷是开篇入口，以及音频步跨度过大。

- **[D] ch52_s1**："打开 **实用工具面板**" —— 无入口说明。Dashboard 九按钮中没有它（ui-inventory 核实）；唯一已知入口是 **Dashboard 内默认按 F6**（keybinds-verified dashboard.utility_panel → UIKeys.UTILITY_TITLE"实用工具面板"）。该信息仅在第一章键位表出现，隔 51 章从未复述，且按教程自身规则应写「默认」并提示可改绑。建议首句改为："在 Dashboard 内按 **F6**（默认，可在 设置→按键绑定 查看）打开 **实用工具面板**"。
- **[C] ch52_s2**：单步横跨三个上下文 —— 实用工具面板（打开音频编辑器...）→ 音频编辑器资源层（含颜色代码操作）→ 影片时间轴音频剪辑层（选择音频.../音频偏移/音量）→ 导出开关层（导出音频/导出 Minecraft 场景声音/音频声道）。三层模型本身是对的（hint 总结得好），但一步之内两次面板跳跃+九个控件名，超出新手单步容量。建议拆为"资源层（编辑器）"与"时间轴与导出层（影片）"两步；另外"颜色代码相关操作"只说"查看"却不说它是干什么的（给波形标记着色？），看了也不懂，建议一句话点明用途或删除。
- **[D·轻] ch52_s2**："打开 **打开音频编辑器...**" —— 绕远路：Dashboard 左侧本来就有"音频编辑器"面板按钮（ui-inventory 核实），上一句刚教完实用工具面板就顺手用它开音频编辑器，反而让用户以为音频编辑器只住在工具面板里。建议主路径用 Dashboard 按钮，实用工具入口作补充。
