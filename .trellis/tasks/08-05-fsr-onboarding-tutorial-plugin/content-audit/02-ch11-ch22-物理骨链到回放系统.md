## 批次概览与最严重问题 Top5

**总体评价**：这一批的键位数值准确率非常高——所有出现的组合键（F5、反斜杠、反引号、Ctrl+N、Ctrl+Z/Y/S、I、1-9/0/R、Ctrl+A、Ctrl+逗号/句号、[ ]、L、B/Alt+B、V、Ctrl+F、Home、Shift+T、3/4/5、Ctrl+R、Ctrl+G、右Alt/右Ctrl 等）全部与 `keybinds-verified.json` 一致；ch12_s6"F5 同时开关 IK 与物理调试"经 `dashboard.keys.toggle_debug = 切换 IK 与物理调试叠加层` 证实；ch16_s7 对 Ctrl+S 双重职责的主动披露、ch15_s6 的占用键位清单都是亮点。主要风险不在"写错键"，而在**只教键不教按钮**（A 类）、**跨章前置倒挂**（关键帧先于回放系统教，C 类）以及少量**源码视角措辞漏进用户文案**（B 类）。

**Top 5 最严重问题**：

1. **[C·重] 关键帧三章（ch17/ch18）与 ch19 建立在"回放"之上，但回放系统 ch22 才教**。ch17_s1 让用户在影片里按 I 插入关键帧，ch19_s3/s4 直接"在回放编辑器里按 3/4/5 切标签"——而"添加回放"到 ch22_s2 才出现。空影片里有没有可插入关键帧的对象，全批未交代（需全局确认：新影片是否自动带一个玩家回放；若无，ch17_s1 按了没反应，新手直接卡死）。
2. **[A·重] ch22_s3 只教 Ctrl+R / 右Alt 开始录制，漏掉右键菜单里的「录制回放...」**（ui-domains：`film.replay.record = 录制回放...`，与「添加回放」同一菜单）。这正是 A 类的标准形态：有按钮先教按钮。
3. **[A·中] 一组"键优先"步骤存在可点击入口却后教或不教**：ch15_s5 反斜杠（存在「打开动画状态管理器」入口 `forms.editor.states.open`）、ch18_s2 Shift+T（hint 自认"比右键找菜单快"，等于承认右键有插值入口）、ch17_s2 数字键选组（插入弹窗本身就列出可点的组条目）、ch17_s3 的 Ctrl+A（右键菜单有「全选」`keyframes.context.select_all`）、ch19_s3/s4 数字 3/4/5（回放编辑器标签页本身可点击）、ch22_s7 Y/Ctrl+G（右键有「传送至回放」`film.replay.orbit.teleport_to_recording`）。
4. **[B·中] 源码视角措辞泄漏进用户可见文案**：ch20_s4 hint"源码里 VECTOR3F_SCALE 单独注册就是为这个"、ch21r_s3 hint"源码里写死了……"、ch19 章标题"29 种可动画属性"（源码注册数）+ ch19_s2 直接抛 double/float/vector3f 类型名。对没接触过 BBS 的玩家是噪声，应翻译成行为描述。
5. **[D·中] ch20 步骤 id 与 order 错位 + ch22_s6 反斜杠双重职责未提示**：ch20 出现两个 `s5` 前缀 id（`ch20_s5_forced_duration` order=5、`ch20_s5_shapes` order=6），后续 id 编号（s6/s7）与 order（7/8）脱节，插件若按 id 渲染步骤号会乱；ch22_s6 把反斜杠教成"全局暂停影片"，而 ch15_s5 刚把反斜杠教成"打开动画状态编辑器"，两处冲突只字未提（哪个上下文优先需实测核实）。

另有一条跨章 C 类贯穿问题：**播放操作（空格/右Ctrl/播放按钮）迟至 ch22_s6 才列出来，但 ch18_s3"每次都播放看效果"、ch21r_s2/s3（录制依赖播放中）反复要求用户播放**——中间几章用户其实不知道怎么播放。

### ch19 什么都能打关键帧：29 种可动画属性（7 步）
