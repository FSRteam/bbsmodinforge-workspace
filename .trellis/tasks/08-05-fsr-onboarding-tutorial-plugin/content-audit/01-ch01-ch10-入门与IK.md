## 批次概览与最严重问题 Top5

总体评价：这份骨架的"引用真实文案"纪律执行得相当好——抽查的全部按钮/字段名（保存为预设...、查看预设...、应用至子集、拷贝姿势、翻转姿势、选取生物...、从您所看向的生物创建形态、选择物品...、从手中获取、试听、内锥角、极向量、链长、柔软度、超出可达范围时拉伸、显示调试叠加层 等）均能在 zh_cn 文案中找到出处，ch09 的"先体验 FK 痛点再引出 IK"设计也是本批次最好的教学设计。主要病灶集中在三处：**第 2 章整章是按键分类学灌输**；**多处把全局快捷键当成首选操作路径而绕过教程自己教过的可点击按钮**；**ch07/ch08 的特殊形态从哪里来始终没有交代**。另有若干步的 userWillSee 与真实界面反馈不符或自相矛盾。

**Top 5 最严重问题：**

1. **[C] 第 2 章整体：读者还没做成任何一件事，先被灌完 11+155 个键和 16 个分类**（ch02_s1/s3/s4/s6）。6 步里 4 步是"无需操作"的认知灌输或纯浏览任务（滚遍 155 键、读遍 16 类说明、背冲突表）。对"对一切一无所知"的读者，这是劝退率最高的一章。建议压缩为 2 步（F9 自查 + 改键演示），其余移到附录或分散到各功能章首次用到时再讲。
2. **[A] ch03_s1 用全局键 B 当首选路径打开伪装面板**，而 ch01_s3 刚刚教过"点击左侧伪装按钮"。同一写法在 ch05_s3、ch06_s2、ch06_s4 反复出现。应改为：点左侧「伪装」按钮为主路径，B 键作为"熟练后可用"的补充。
3. **[D] ch07/ch08 共 14 步全部依赖一个从未教过的前置动作："选择/新建一个方块（物品/文字标签/广告牌/拖影/拉伸/声音/圆锥声音）形态"**。伪装面板右键菜单经核实只有 添加类别.../复制形态/粘贴形态/移除/重命名/分享/导出 等（bbs.ui.forms.categories.context.*），**不存在任何"新建形态"入口**；这些特殊形态在面板的哪个分类下、如何获得，教程从头到尾没说。读者在第 7 章第一步就会卡死。
4. **[D] ch03_s3 让用户"按 F5 切第三人称看变身效果"，但此时 Dashboard 还开着**——按教程自己的冲突表（ch02_s4）"F5：编辑器=切换debug"，这个 F5 大概率触发的是 BBS 调试开关而不是原版视角切换。正确写法：先按 0 关闭 Dashboard，再按 F5。ch04_s3 的括号注记同样带病。

### ch01_dashboard_overview —— 认识 Dashboard（7 步）

- **[A] ch01_s6**｜instruction：「按 **Ctrl + N** 新建一个标签页」｜影片标签栏存在可点击的新建入口（ui-domains 实证：`bbs.ui.film.tabs.new_tab => 新标签页`，且同组有 `tabs.context.close_left/close_others/close_right`，说明新标签页就在标签栏右键菜单里）｜新手对组合键的记忆负担远大于"右键点一下"，且 Ctrl+N 在浏览器里是开新窗口，容易混｜建议改为："右键顶部标签栏 → 点击「新标签页」；熟练后也可按默认快捷键 Ctrl+N"。（兼 C：此步还强迫读者切到尚未介绍的影片面板，属于为讲功能而跳面板。）
- **[A] ch01_s5**｜instruction：「按 **Ctrl + S**（Dashboard 内默认快捷键）」｜自动隐藏同样可在设置界面勾选完成（ui-domains 实证：skins_themes 域 `bbs.config.refreshed.dashboard_auto_hide_taskbar => 自动隐藏仪表盘边框`）；更糟的是 editor.save 也是 Ctrl+S（keybinds-verified），工作台内按 Ctrl+S 同时是"保存"——现在教会新人"Ctrl+S=藏任务栏"，以后他每次想保存都会把任务栏藏掉｜建议改为：主路径写"BBS 设置 → 外观 → 勾选/取消「自动隐藏仪表盘边框」"，并明确提醒"编辑器里 Ctrl+S 默认是保存，别记混"；Ctrl+S 切换任务栏作为进阶提示放在最后。（兼 C：截图/录制场景的琐事不该出现在第 1 章。）
- **[A·轻微] ch01_s4**｜instruction：「在 Dashboard 打开的状态下，按键盘 **F9** 键」｜F9 快捷键列表确实没有等价按钮，教学它本身合理；但 instruction 未写「默认」二字、也未给出"F9 无效时去 设置 → 按键绑定 查看"的兜底——这正是 keybinds-verified.json `_meta.tutorial_rule` 明文要求的两件事｜建议补齐："按键盘 **F9**（默认）；如果没反应，说明键位被改过，可在 Dashboard 右上角设置 → 按键绑定 里查看"。ch02_s3 复用 F9 时同样漏写。

- **[C] ch01_s5 + ch01_s6（合并一条章节级问题，落点 ch01_s5）**｜第 1 章 7 步里有 3 步（s4/s5/s6）在教"管理编辑器"而非"使用编辑器"，读者此刻连一个形态都没变过｜自动隐藏、多标签属于低频知识，放在这里挤占了建立成就感的机会｜建议 s5 整体后移到讲设置的章节，s6 压缩成一句提示并入后续影片章。

整体评价：这是全批次最偏离"普通玩家"视角的一章：在读者还什么都没做出来之前，先要求他们理解双层键位、记住 11 个全局键、滚完 155 个编辑器键、读完 16 类冲突说明。唯一的动手步骤（s5 改键演示）反而设计不错，但 userWillSee 与 hint 自相矛盾。强烈建议整章瘦身。
