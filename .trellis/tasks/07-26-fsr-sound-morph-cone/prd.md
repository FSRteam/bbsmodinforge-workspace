# 圆锥声音伪装 Morph 与可视化

> 2026-07-27 回归扩展：圆锥 Form 与球形 Form 共用五条复合声音关键帧、专用音频选择器、可重复试听，以及方块/实体反射与分别穿透合同；详细验收以兄弟任务 `07-26-fsr-sound-morph-sphere/prd.md` 的“用户回归补充”为准。圆锥的 `发射形状` 复合轨道包含 range、innerAngle、outerAngle、outerGain。

父任务:`07-26-fsr-sound-morph-parent` · 依赖:`07-26-fsr-sound-acoustic-core`、`07-26-fsr-sound-morph-sphere`

## Goal

两件事:

1. **圆锥声音 Form** —— 顶点即播放点,沿锥轴张开,锥高即最远传播距离,内外锥角与朝向可编辑。
2. **两个 Form 的世界内可视化** —— 球体与锥体线框、强度分层、可拖拽编辑。可视化统一放在本任务,因为球与锥共用同一套绘制原语,拆开会重复实现。

## Requirements

### R1 圆锥 Form

- R1.1 `SoundConeForm extends AbstractSoundForm`,追加 `range`(锥高 = 最远距离)、`innerAngle`、`outerAngle`、`outerGain`。
- R1.2 **朝向复用 `Form.transform` 的旋转**,不设独立方向字段(与参考实现一致,且免费获得既有 gizmo)。
- R1.3 **硬语义**:圆锥顶点 = Form 位置 = 播放点;锥高 = 最远距离,超出即静音。
- R1.4 实现形状增益:内锥全增益,内外锥间平滑过渡到外锥增益,外锥外为外锥增益。
- R1.5 内锥角自动 clamp 到不超过外锥角,避免非法组合。
- R1.6 以 `Link.bbs("sound_cone")` 注册,并完成渲染器/编辑器注册与编辑面板(模式同子任务 2)。

### R2 形状可视化

- R2.1 球形:三个正交平面的圆 + 三条轴线构成线框。
- R2.2 锥形:中轴线 + 母线 + 外锥底环 + 内锥环,顶点在播放点。
- R2.3 **可视化几何与声学换算共用同一函数**,保证"看到的边界"就是"声音消失的边界"。
- R2.4 线宽随尺寸自适应;辅助图形穿墙可见(不写深度、不做深度测试)。

### R3 强度可视化

- R3.1 按距离衰减公式分层绘制等强度环/截面(如参考距离、-6dB、-12dB、最大距离),用颜色或透明度区分。
- R3.2 分层结果必须由**实际使用的衰减公式**算出,不得另写一套近似 —— 否则可视化会撒谎。
- R3.3 反射开启时可选显示反射路径示意。

### R4 编辑交互

- R4.1 选中该 Form 时,在世界中显示可拖拽手柄:锥高、外锥角、内锥角(球形则为半径)。
- R4.2 拖拽实时改写对应字段,并与面板数值双向同步。
- R4.3 拖拽手柄的几何与可视化共用同一真相源,不得各算各的。

### R5 显示时机

- R5.1 可视化仅在编辑态/选中态显示,不影响最终渲染输出(PRD R6.5)。
- R5.2 提供全局开关,可选择"始终显示所有声音 Form 的辅助图形"。

## Acceptance Criteria

- [ ] 能创建 `sound_cone`,参数序列化往返一致。
- [ ] **圆锥顶点确实位于播放点,锥高等于最远距离** —— 可视化与听感双向验证(走到锥高边界处声音消失)。
- [ ] 转动 Form 朝向,锥体方向跟随;站在内锥内 / 过渡区 / 外锥外,音量呈现三段差异。
- [ ] 调整半径/锥高/衰减模型/反射次数,世界内可视化实时跟随。
- [ ] 强度分层显示的"听不见距离"与实际听感一致。
- [ ] 拖拽手柄可改锥高/内外角,与面板数值双向同步。
- [ ] 可视化不出现在最终渲染输出中。
- [ ] `cd new && ./gradlew check` 真实 exit code 为 0,日志确认 BUILD SUCCESSFUL 且 0 FAILED。
- [ ] 用户游戏内冒烟确认。
