# 退场动画机制

## Goal

补齐动画对称性:弹层(UIOverlay)与右键菜单(UIContextMenu)关闭时播放反向动画后再移除,消灭"出现有动画、消失瞬间蒸发"的断裂感。正式解决 v1 遗留清单中的"overlay 关闭反放残影"。

## Requirements

- R1 关闭请求后元素进入退场态:反向播放出现动画(淡出 + 缩放回起点),完成后从 UI 树移除。
- R2 退场期间元素**立即停止交互**:命中判定失效、不接收键盘/鼠标事件;膜(backdrop)同步淡出且不再拦截点击下层的输入语义变化需与 macOS 一致(退场即视为已关闭)。
- R3 退场动画参数默认复用该接入点的出现动画条目(时长/弹簧同源);`motion.enabled=false` 或该条目 disabled 时,关闭行为与 v1 逐位一致(立即移除)。
- R4 连打保护:退场中再次打开同类弹层、或退场中元素被父级强制移除,均不得崩溃或残留幽灵元素。
- R5 ESC 连按、点击膜关闭、代码调用 close 三条路径行为一致。

## Out of Scope

- 通知/面板切换的退场(v1 已有信封/纱机制)。
- track 级退场定制(motion-tracks 任务在此机制上扩展)。

## Constraints

- 这是 v1"render-only 不碰生命周期"红线的**唯一**松动点,范围锁定 UIOverlay 与 UIContextMenu 两个封闭出口;其它元素生命周期不动。
- 依赖 motion-engine 的 alpha 栈(整面板淡出)。
- 行为开关可退回 v1 立即移除路径(回滚点)。

## Acceptance Criteria

- [ ] 弹层/右键菜单关闭有对称退场动画;动画关闭时与 v1 行为逐位一致。
- [ ] 退场期间点击原弹层区域,事件到达下层元素(或膜语义正确),无幽灵交互。
- [ ] 快速连续开/关无崩溃、无残留、无重复元素。
- [ ] 全量 check 真实 exit code 0;用户游戏内冒烟确认。
