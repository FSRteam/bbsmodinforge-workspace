# P1 传输与画质反馈

## Goal

让传输层的状态变化对用户可见且不打扰。当前 WebRTC↔JPEG 降级完全静默且伴随闪屏；自动画质每次换档都重连 media socket 并弹 toast，链路抖动时反复闪屏 + 刷屏；toast 单条 3.2s 自动消失、互相覆盖、无历史，用户来不及读也无法回看。本任务为纯前端（`app.js`），不碰协议。

## 依据（审计 file:line）

- WebRTC→JPEG 降级静默：`app.js:4533`（fallbackToJpegMedia）、`4525`（switchToRtcMedia）
- 降级触发重连闪屏：`app.js:4536-4539`
- 协商停滞无进度提示：`app.js:2490-2495/2483`
- 首帧门控可能掩盖黑屏：`app.js:2415-2424/2586-2592`
- 自动画质每次改档重连 media：`app.js:3855→3847`
- 自动画质抖动 toast 刷屏：`app.js:3856`（护栏在 2109/2120/2126）
- toast 单条覆盖无历史：`app.js:5213-5219`

## Requirements

### toast 队列 / 历史（基础设施，先做）
- `note()` 改为**队列化**：多条消息依次展示而非互相 `clearTimeout` 覆盖；同一时刻至多一条可见，其余排队。
- 相同消息在短窗口内**去重/合并**（避免刷屏），可显示 `×N` 计数。
- 提供**可回看历史**：一个可展开的消息历史列表（保留最近 N 条，含时间戳、级别 info/warn/error），用户可事后查看被冲掉的提示。
- 保留无障碍：`#liveStatus` aria-live 仍播报最新一条。

### 传输降级可见且平滑
- WebRTC→JPEG 回退、JPEG→WebRTC 升级都必须有**面向用户的可见提示**（经队列化 note），文案区分\"已切换到兼容视频通道\"/\"已启用低延迟视频\"，不使用内部 state 术语。
- 降级时避免/最小化黑屏：回退期间保留上一帧或显示明确的\"正在切换视频通道…\"占位，而非静默 stall。
- WebRTC 协商进行中显示\"正在建立低延迟视频…\"进度态；ICE 慢/停滞时给出提示而非空/静止画面对着用户。
- 首帧门控：轨道到达但迟迟无可解码帧时，有超时兜底提示或触发回退，不无限黑块。
- `video.play()` 被拒（autoplay 限制）时给出可见提示（如\"点击画面以启用视频\"），不静默黑屏。

### 自动画质防抖
- 自动画质换档**不再每次都重连 media socket 造成闪屏**：优先无缝调整（若协议/服务端支持在同 socket 上变更参数则用之；否则合并抖动、显著提高重连门槛）。
- 换档 toast **节流/合并**：短时间多次换档只提示一次（或汇总为\"画质已自动调整\"），不逐次弹窗。
- 保留既有护栏（15s 冷却、降档需 2 个 BAD 窗口、升档需健康窗口）；本任务只降低其\"可见打扰\"与\"闪屏\"成本。

## Acceptance Criteria

- [ ] 连续触发多条提示时，逐条排队展示、不互相覆盖；相同提示合并计数。
- [ ] 可展开查看最近若干条提示历史（含时间/级别）。
- [ ] WebRTC↔JPEG 切换有可见、非术语的提示；切换期间无长时间纯黑屏（保留旧帧或占位）。
- [ ] WebRTC 协商中/停滞/首帧超时/autoplay 被拒 各有对应可见状态或兜底，不留静默黑屏。
- [ ] 自动画质在链路抖动下不再逐次闪屏 + 逐次弹窗；换档提示被节流/合并。
- [ ] 手动画质、隐藏页面、无 surface、主动重连等既有护栏行为不回归。
- [ ] `bbs-web-remote/` 前端相关 Node 回归（`namespace.WebTest`）通过；无协议/wire 改动。

## 约束

- 纯前端 `app.js`（可含 `styles.css`/`index.html` 的历史面板 DOM）。不改 wire、不改服务端。
- 复用现有 `MediaMetrics`/`AdaptiveQualityController`/`HybridMediaTransport` 结构，增量改造，勿重写。
- 无缝换档若需服务端支持而当前不具备，则以\"提高重连门槛 + 合并提示\"达成\"不打扰\"，并在 design.md 记录该取舍。

## Out of Scope

- 错误串本地化的全面覆盖（属 `wr-ux-error-i18n`；本任务新增文案补 en/zh key）。
- 协议层新增无缝换档消息（若判定需要，登记为后续任务，不在本任务扩协议）。
